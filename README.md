### 🚀 프랜차이즈 인큐베이팅 3.0

| | 방식 |
| --- | --- |
| **1.0** | 사람의 경험과 감으로 키우던 시대 |
| **2.0** | 매뉴얼과 시스템으로 복제하던 시대 |
| **3.0** | AI 에이전트가 기획·운영·교육을 함께 하는 시대 |

### 🛠 만들고 있는 것

- 현장 정산·배차 자동화 도구
- 옵시디언 기반 세컨드 브레인 (지식 관리)
